## ✨ Back from Zero

Between 2021 and 2022, byZero built a lot of things, between 13 and 14 years old and mostly by trial and error. Some went offline, some were never finished. **Back from Zero** brings them back: the original look, the original quirks, and finally the features from the old idea lists.

| | Project | Then | Now |
| --- | --- | --- | --- |
| 🍩 | **[ZeroBot](https://github.com/EinfachRuwen/ZeroBot)** | A Discord bot for one server | A playable time capsule at [zerobot.by0.link](https://zerobot.by0.link) |
| 🧱 | **[WebsiteGenerator](https://github.com/WebsiteGenerator/WebsiteGenerator)** | A Python script in the terminal | A generator in the browser |
| 🔢 | **[Counter](https://github.com/EinfachRuwen/Counter)** | An Android app, clicked together in Sketchware | A web app |

## The Revival

No Discord server, no tokens, nothing to install. Type `/` and ZeroBot answers just like he did in 2021.

- **All commands, original replies.** *“Seriously? You want to see all commands? … Shut up. GET OUTTA HERE”*
- **Flip any answer** to see the Python code that produced it.
- **The old bugs are still in**, with a small note explaining each one.
- **Dead APIs replaced** by free ones that need no key. The behaviour stays the same.

## The story

| When | |
| --- | --- |
| **Mar 2021** | First commit and **v1.0**. Prefix commands for a single server. |
| **May 2021** | **ZeroBot goes public:** *“I made the bot public :D — YEAHHHHHHHHHH FINALLY”*. Slash commands follow two weeks later. |
| **Jun–Jul 2021** | A website, giveaways, `/meme`, `/weather` and a StatusBot. A calculator lasts exactly one day: *“Remove calc cause of Security”*. |
| **2022** | Offline, then archived. |
| **2026** | Back from Zero. |
